POKEMON HACK ROOMS
==================

Versión inicial del proyecto.

ESTRUCTURA
----------
index.html       -> página principal
css/style.css    -> diseño visual
js/app.js        -> Rooms, buscador, filtros, ranking y formulario

COMO ABRIR
----------
1. Extrae el ZIP.
2. Entra en la carpeta.
3. Abre index.html con Google Chrome.

IMPORTANTE
----------
Esta versión es una interfaz frontend. Las Rooms son datos locales de demostración.
Para tener cuentas, salas reales, chat, jugadores en tiempo real y autenticación
haría falta conectar un backend/base de datos.

El proyecto es fan-made y no está afiliado oficialmente con The Pokémon Company.
